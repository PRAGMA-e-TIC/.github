# PRAGMA-e-TIC

Petite société française à dimension familiale, à l'intersection des **systèmes d'information de gestion** et des **productions multimédia**.

## Ce que nous faisons

- **Conseil SI** — ERP, gestion client, gestion financière, intégration et pilotage de projets pour des clients entreprise.
- **Productions multimédia** — graphisme, musique, vidéo, cinéma, littérature, jeux vidéo. Diffusion en propre et pour partenaires.

## Notre posture technique

Stack **100 % open source** sur tout ce que nous développons. Hébergement souverain (OVH) pour les briques sous notre contrôle, services SaaS européens (Odoo, Qonto, Dougs) pour la gestion. Python en priorité côté backend, TypeScript / Next.js côté front, mobile en PWA + Capacitor.

## Repos publics

Ce que vous trouvez ici est soit un module open source que nous publions, soit un projet client ouvert avec son consentement. Nos travaux internes vivent dans des repos privés.
